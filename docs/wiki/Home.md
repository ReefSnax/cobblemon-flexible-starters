# Cobblemon Flexible Starters

Cobblemon Flexible Starters extends Cobblemon's native starter picker so new trainers can choose a configurable team of starters before confirming.

## Highlights

- Server-authoritative teams of **1–6** starters.
- Duplicate and group-limit enforcement, including the default pseudo-legendary cap.
- Native picker controls, selected-team tray, ball/nature details, and category-list feedback.
- Works with Cobblemon's normal custom starter categories.

## Compatibility

- Minecraft Java 1.21.1
- Java 21
- NeoForge 21.1.x
- Cobblemon 1.8.x (tested with 1.8.4)

Install the same release on the dedicated server and every client.
